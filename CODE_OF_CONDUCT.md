UNITY DIALOGUE SYSTEM CODE OF CONDUCT

Our Goals

The Unity Dialogue System project is committed to maintaining an open and welcoming and collaborative community.
People of all backgrounds and experience levels are welcome and should feel comfortable participating in the project.

Expected Behavior

* Treat other contributors and users with respect and patience
* Welcome people regardless of their background
* Give constructive feedback focused on code or documentation
* Accept constructive criticism respectfully

Unacceptable Behavior

* Harrassment or threats
* Personal attacks or insults
* Discrimination
* Trolling
* Unwanted sexual language
* Publishing another person's private information

Reporting Violations

Report the violation with the following:

* A description of the violation
* Where and when it happened
* Relevant links or screenshots

Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing these rules.
Maintainers have the rights to edit, hide, or remove comments, issues, pull requests, commits, or other contributions that violate the code of conduct

Community Values

1. Respect
2. Collaboration
3. Accessibility
4. Constructive Feedback
5. Responsibility
